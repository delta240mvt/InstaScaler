# Audyt interfejsu — 8 września 2026

Zakres: panel użytkownika, współdzielone komponenty panelu, przeglądarkowy klient Core, szablony kampanii. Strony publiczne, formularz logowania, CSS i testy E2E są w osobnym zakresie głównego agenta.

## Naprawy

- Panel czytał nieistniejące `payload.success`, mimo że Core zwraca `{ data }`. Wszystkie odczyty w tym zakresie korzystają teraz z faktycznego kontraktu Core; `coreFetch` odrzuca odpowiedzi HTTP z błędami.
- Lista i szczegóły kampanii potwierdzały zmianę stanu nawet po HTTP 4xx/5xx. Aktualizacja widoku następuje po potwierdzonym powodzeniu; błędy są widoczne po polsku. Usuwanie również respektuje odpowiedź serwera.
- Duplikowanie zachowuje wyzwalacz DM, wiadomość uzupełniającą, opóźnienie, cel, etykiety i pozostałe ustawienia wysyłki, ale nie przenosi identyfikatorów, historii ani uprawnień do raportu. Kopia startuje wstrzymana. Zapisana przez użytkownika treść nie jest tłumaczona.
- Kolejny wiersz importu resetuje opcjonalne kroki i drugi link z poprzedniej kampanii. Nagłówki CSV oraz tokeny `{link}` i `{username}` pozostają zgodne z protokołem.
- Skrzynka bez połączonego konta kończy ładowanie. Odpowiedzi wcześniejszego konta lub rozmowy nie zastępują aktywnego widoku. Nie można przełączyć rozmowy podczas wysyłania. Błąd przywraca szkic; dostęp do opcjonalnego sessionStorage nie blokuje aplikacji.
- Wybór postów czyści poprzedni błąd i bibliotekę przy zmianie konta. Lista kampanii, dziennik, pulpit i statystyki zabezpieczają odczyty przed nieaktualnymi odpowiedziami po zmianie filtrów.
- Filtry dziennika używają rzeczywistych statusów Prisma: QUEUED, PROCESSING, SENT, SKIPPED, RETRYING, FAILED. Etykiety są polskie. Nieznany status nie jest już przedstawiany jako oczekujący.
- Błędy HTTP i sieci mają polskie, bezpieczne komunikaty. Kod maszynowy i requestId pozostają dostępne. `Retry-After` jest przekazywany jako opcjonalne `retryAfterSeconds`.
- Wylogowanie, odłączenie konta i odrzucenie sesji czyszczą prywatne bufory Instagram w sessionStorage. Awaria kontroli sesji daje możliwość ponowienia zamiast udawania wylogowania.
- Wszystkie stałe teksty panelu, potwierdzenia, etykiety dostępności, przykłady, podglądy i osiem szablonów kampanii są po polsku. Daty i liczby korzystają z pl-PL; nazwy protokołu, identyfikatory i treść użytkownika są zachowane.
- Usunięto pozostałości złoto-brązowej palety i font-serif z komponentów. Jasny akcent ma ciemny tekst. Nazwa produktu InstaScaler pozostaje z podpisem DELTA240MVT.
- Pola edytora i przełączniki mają konkretne etykiety, radio-przyciski i podglądy używają semantyki stanu. Zamknięta mobilna nawigacja jest niewidoczna dla tabulacji; otwarcie ustawia fokus, Tab/Shift+Tab utrzymuje go w panelu, zamknięcie przywraca fokus.
- Dłuższe etykiety statystyk zawijają się. Słupki siedmiodniowego wykresu mają obliczoną wysokość w pikselach. Wiadomości w makiecie telefonu przewijają się zamiast znikać poza ramką.
